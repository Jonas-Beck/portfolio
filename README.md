# jonasbeck.dk

Source for [jonasbeck.dk](https://jonasbeck.dk), my personal site, built with Astro and Tailwind CSS.

## Development

Tools are pinned with [mise](https://mise.jdx.dev), and dependencies are installed with aube.

```sh
mise install
aube install
mise run dev
```

Run `mise run check` before pushing (formatting, type-check, tests), and `mise run build` to build to `dist/`.
